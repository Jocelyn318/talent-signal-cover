# 随包字体

字体文件来自 Google Fonts 官方仓库，完整保留字体内名称；TS Sans SC / TS Inter 仅为浏览器 FontFace 别名。

- Noto Sans SC Variable: https://github.com/google/fonts/tree/main/ofl/notosanssc
- Inter Variable: https://github.com/google/fonts/tree/main/ofl/inter

两者的 SIL Open Font License 已分别随包保存。未子集化，供人工改写中文、英文使用。首次加载体积较大，但无需联网。
