# Talent Signal Cover

未来复古封面 Skill 与本地文字编辑器。流程是 **理解内容 → 提交提案 → 等待确认 → 无字背景 → 按需独立排字**。

## 使用

首次使用请看 [同事部署与使用说明](DEPLOYMENT-AND-USAGE.md)：访问邀请、Skill 安装、macOS／Windows 本地启动、封面工作流、保存交接和排错。

Skill 入口：[SKILL.md](SKILL.md)。将整个目录保留为 `talent-signal-cover`，通过支持本地 Skill 的客户端加载；不要只复制 SKILL.md，否则图片、字体与编辑器会缺失。可将整个目录复制到自己的技能目录后按客户端要求重新加载。

示例请求：`使用 $talent-signal-cover 阅读下面的正文，先给我封面提案，确认前不要生图。`

图像生成依赖运行环境提供的图像工具，本仓库不附带生成模型、API 密钥或已训练权重。编辑器无需生图服务，运行依赖 Python 3 和现代桌面浏览器；可选项目生成和测试使用 Node.js 18+。

## 打开编辑器

在仓库根目录运行：

```sh
python3 scripts/serve.py
```

在本机访问终端打印的链接。端口占用时用 `python3 scripts/serve.py --port 8766`。服务器停止后链接不可用；这不是永久在线网站。仅服务 editor/ 目录，不公开原始参考图或整个磁盘目录。

上传背景后编辑三个独立文字层，保存 JSON 可继续修改。关闭前手动保存；无自动保存。详见 [编辑器说明](references/editor.md)。

## 包含内容

- 15 张用户提供的元素参考和用途说明。
- 地图工作台、蓝底环带两个已认可范围明确的样例。
- 提案确认、配色独立、无字生成和反馈规则。
- 本地编辑器、随包字体与 OFL 许可、启动和项目生成脚本、测试。

用户新参考默认只借元素及关系，不借背景颜色，除非明确要求。环带、地图、手势不是固定模板。
