# 视觉规则 v1.1

这是设计偏好与工作方法，不是模型训练权重；风格仍可按反馈演进。

## 已认可方向

统一为编辑感未来复古主义：像 20 世纪科幻杂志经当代平面设计重新编辑。可用摄影拼贴或套印插画，保持有趣、克制、旧印刷颗粒、轻微胶片质感与超现实尺度关系，不做写实电影海报。用熟悉物件之间自然却不可能的关系吸引注意，不把文章逐段画成解释图。保留纸、衣料等材料差异、柔和边缘与适度喷绘体积；避免塑料 CG、末日废墟和覆盖全图的浓重污损。参考用于理解意图，最终材质与渲染统一，不把混用参考直接拼成风格不一致的画面。

优先配色关系：柔和灰青蓝背景＋暖米白／浅沙色主体＋深色摄影元素；暖橙红可作少量点缀。蓝底环带 demo 明确获认可，而同构图的大面积红底被否定。不因此禁止所有红色，也不锁死所有主题只能蓝色。未验证配色要在提案中明确。

新参考只借元素及关系，不自动借背景颜色。配色应由已认可基准或用户单独确认的方案提供，提示词明确排除参考背景色。不能因为某张图带红底就跟着整张变红。元素固有色可按栏目配色协调，不把新参考的其它特征自动升级为规范。

## 意象、构图与材质

- 正文关系先于物件选择。一个焦点、一种主要空间异常是有用起点，不是机械数量限制。
- 运用弧线、姿态、视线、非对称与尺度组织动势。避免等距排队、居中产品陈列或标注流程图。
- 留白与美感和含义同样重要；无法通过画面成立的关系，不用长篇解释补救。
- 地图、桌子、圆环、手势、星球、CRT 都不是通用模板。不为“变化”丢掉好构图，也不为统一照搬主体。
- 人物为概念角色，不冒充嘉宾。解剖和接触关系要检查；巨手可能被读成控制他人，不自动等于责任范围扩大。
- 上部安排低细节文字净空，主体通常中下部，底部留栏目区域；按实际内容调整，不强制每张相同比例。

## 默认避用项

尽量不要出现：生成真人人脸、常规蓝紫科技感、发光电路、无意义圆环、复杂悬浮元素、满屏信息、互联网活动海报感。人物并非禁用，可采用背影、仅手部、遮面或无面部细节形象。有内容作用的回路、环带可使用，但不能因为标题含 Loop 就自动加圆环。科幻感优先来自意象和尺度关系，不来自装饰堆砌。用户对某次任务明确提出不同要求时记录局部例外，不自动变更全局规则。

## 图文分离与裁切硬约束

生成背景没有任何标题、副标题、栏目名和水印；文案属于独立文字层。带字参考图不作为需要复制的整张版式。截图中的编辑器边框、安全线、选中框不能成为画面元素。

9:16 画布中，所有核心视觉和文字必须在正中央 3:4 安全区内完整保留。默认母版 1080×1920，安全区为 x=0–1080、y=240–1680，裁后 1080×1440。任意 9:16 尺寸对应纵向 12.5%–87.5%；安全区内再留适度边距，避免贴边。

核心包含承载隐喻的主体、手势、交接物、关键连接关系，以及标题、副标题、栏目名全部文字。只有非核心背景与允许截断的装饰可延伸到上下裁切带。不能把人体或关键物件的意外裁断解释成已经满足安全区。

生成前把边界写入意图包和提示词；生成后查看完整图及实际中央 3:4 裁切预览；后续排字再检查三个文字层的完整边界。若核心被裁，调整构图或排版后复核，不能仅凭提示词声称保证裁切。预览不画安全线进正式成图。3:4 输入背景用于 9:16 时会左右裁切，必须按实际显示变换重新检查，不能假设天然安全。

文字体系：Noto Sans SC 粗黑主标题（900），常规副标题（400），Inter 粗体栏目名（700）。栏目名初始 64 px；标题 112 px／1.17、副标题 45 px／1.3 为原获认可样稿起点，可随长度调整。保留人工换行和锁定，不靠无限缩字容纳内容。

原标题色 #F7F4EE，强调色 #FF8254，浅底栏目名 #173D46；这些是文字参数，不是对纹理背景精确取色。具体位置与颜色必须服从当前背景的可读性。
