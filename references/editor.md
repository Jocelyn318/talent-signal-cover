# 本地编辑器

在本 Skill 根目录运行 `python3 scripts/serve.py`，按终端显示的本机链接打开。可用 `--port 8766` 更换端口；默认 8765，冲突会清楚报错，不接管其它服务。终端保持运行；Ctrl+C 停止后链接会失效。

仅提供本机静态编辑器，不自动部署网站，不在页面内调用生图 API。字体随包，不依赖外部 CDN。首次加载中文字体较大，请等“字体已就绪”。

1. 上传／替换无字背景；替换只改背景，保留已有文字。
2. 切换主标题、副标题、栏目名三个图层，编辑文字、字号、换行、位置、颜色、强调词。默认空标题副标题，栏目名 64 px 且隐藏；需要时打开“显示图层”。
3. 人工改动自动标记“防 AI 覆盖”；仍可人工继续改。AI 更新用 `window.coverEditor.applyAiPatch`，会跳过锁定层。不要通过重建项目绕过锁定。
4. 保存项目下载 JSON，内含背景与排版。页面没有自动保存，刷新／关页前请保存；下次用“打开项目”导入。
5. 预览 9:16 和中央 3:4，调整背景焦点与缩放，检查裁切和警告后导出。选择框和安全线不进导出图。

可选：`node scripts/new-project.mjs 背景.png 输出.json` 把本地 PNG／JPEG／WebP 变成可导入空文字项目。不覆盖已有文件，不修改背景，保留元数据中的原始尺寸解释由使用者记录。已有项目不要用它替换。

项目只接受嵌入图片数据，不接受外部图片 URL。两个导出尺寸为 1080×1920 和 1080×1440。3:4 背景适配 9:16 时会裁掉左右部分；裁切并不生成缺失内容。

纯改字先定位可编辑 JSON。只有一张压平带字图片时，无法直接还原独立文字层；应请求原项目或无字背景，不重生全图冒充无损改字。目标层若已锁定，报告跳过并请用户解锁该层或明确授权本次解除该层锁定，不能把泛化“改副标题”当成绕过锁的许可；其它锁定层和背景保持不变。

测试：`node --test tests/*.test.cjs`；服务与包检查：`python3 -m unittest discover -s tests -p 'test_*.py'`。
